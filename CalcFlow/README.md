### 💡 Sobre o CalcFlow

CalcFlow é uma aplicação web moderna desenvolvida com **HTML**, **CSS** e **JavaScript puro**, oferecendo uma interface elegante, responsiva e intuitiva para cálculos rápidos e eficientes. O projeto foca em aplicar conceitos de lógica de programação avançada, manipulação de strings, parsing seguro de expressões matemáticas e design de interfaces interativas.

> **"Fast • Elegant • Smart"** — Rápido, Elegante e Inteligente.

**Funcionalidades Principais:**
- Parser seguro para avaliação de expressões matemáticas (sem uso de `eval()`)
- Histórico de cálculos com persistência via `localStorage`
- Alternância entre tema claro e tema escuro
- Suporte a operações avançadas: Potência (x²), Raiz Quadrada (√) e Porcentagem (%)
- Design responsivo com CSS Grid e Flexbox
- Favicon e manifest personalizados para PWA

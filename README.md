## Projetos disponíveis

### [CalcFlow](./CalcFlow)

<div align="center">

> **Fast • Elegant • Smart**

</div>

Uma calculadora web moderna, responsiva e intuitiva, criada com HTML, CSS e JavaScript puro.

| Recurso | Descrição |
|---|---|
| Operações | Adição, subtração, multiplicação, divisão, porcentagem, raiz e potência |
| Segurança | Parser próprio para expressões matemáticas, sem `eval()` |
| Histórico | Até 20 cálculos salvos no `localStorage` |
| Temas | Alternância entre modo claro e escuro |
| Experiência | Suporte ao teclado, layout responsivo e interface adaptada para celular |
| PWA | Manifesto configurado para instalação como aplicativo web |

## Executar localmente

O CalcFlow é uma aplicação estática e não exige instalação de dependências. Para executá-lo com um servidor HTTP local:

```bash
git clone https://github.com/gatlyciopierre6-boop/projetos.git
cd projetos/CalcFlow
python3 -m http.server 5500
```

Depois, abra [http://localhost:5500](http://localhost:5500) no navegador.

Como alternativa, usando Node.js:

```bash
npx serve . -l 5500
```
